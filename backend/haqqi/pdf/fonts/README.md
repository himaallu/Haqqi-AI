# Fonts for the complaint PDF

Self-hosted so every machine (laptop, CI, the Render image) renders the same glyphs. All are Noto fonts under the
SIL Open Font License 1.1 (`OFL.txt`), downloaded on 3 Oct 2026 from `github.com/google/fonts` (`ofl/<family>/`).

| File | Script | Used for |
| --- | --- | --- |
| NotoNaskhArabic.ttf | Arabic | The complaint letter |
| NotoNastaliqUrdu.ttf | Arabic (Urdu) | Urdu translation column |
| NotoSansDevanagari.ttf | Devanagari | Hindi and Nepali |
| NotoSansMalayalam.ttf | Malayalam | Malayalam |
| NotoSansBengali.ttf | Bengali | Bengali |
| NotoSans.ttf | Latin | English and Tagalog, digits |
